# Fortran2003 模块对比工具

这个工具用于系统性地对比 Fortran2003 模块的旧版本（单文件 `.bak`）和新版本（重构后的目录结构）。

## 文件说明

- `compare_fortran2003_simple.py` - 主要对比脚本（推荐使用）
- `compare_fortran2003.py` - 另一个版本的对比脚本（通过导入模块，可能遇到循环导入问题）

## 使用方法

直接运行脚本：

```bash
python3 compare_fortran2003_simple.py
```

或者：

```bash
./compare_fortran2003_simple.py
```

## 对比内容

脚本会对比以下内容：

1. **类定义**
   - 类的数量统计
   - 新增的类
   - 删除的类
   - 修改的类（继承关系、方法、属性的变化）
   - 未变化的类

2. **函数定义**
   - 函数的数量统计
   - 新增的函数
   - 删除的函数

3. **导入依赖**
   - 导入的数量统计
   - 新增的导入
   - 删除的导入

4. **文件结构**
   - 文件大小对比
   - 代码行数对比
   - 文件组织方式对比

## 输出

脚本会在控制台输出详细的对比结果，并生成一个文本报告文件：

- `fortran2003_comparison_report.txt` - 完整的对比报告

## 工作原理

脚本通过解析源代码文件（使用 Python AST）来提取信息，而不是导入模块。这样可以：

- 避免循环导入问题
- 更快速地分析大型代码库
- 提供更详细的源代码级别的对比

## 注意事项

1. 脚本需要 Python 3.6+
2. 确保旧版本文件 `src/fparser/two/Fortran2003.py.bak` 存在
3. 确保新版本目录 `src/fparser/two/Fortran2003/` 存在
4. 脚本会分析所有 `.py` 文件，包括 `__init__.py` 和 `nodes/` 目录下的所有文件
